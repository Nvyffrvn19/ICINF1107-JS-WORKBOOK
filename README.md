## ⚡ Cómo usarlo

1. 📥 **Clona** el repositorio:
```bash
   git clone https://github.com/Nvyffrvn19/ICINF1107-JS-WORKBOOK.git
   cd ICINF1107-JS-WORKBOOK
```
2. 🌐 **Abre** `index.html` en tu navegador (doble clic basta).
3. 🛠️ **Abre la consola** con `F12` → pestaña **Console**.
4. ✅ **Revisa los resultados:** el bloque `VERIFICACIÓN` imprime `PASS` / `FAIL` por ejercicio y el total de ejercicios resueltos.
5. 🔄 Si editas `scripts.js`, **guarda y recarga** la página.
